# QarHub

Первая работающая версия автомобильного сообщества Казахстана. React + TypeScript + Vite, адаптивный интерфейс на русском языке.

## Запуск

Открой эту папку в VS Code. В терминале Git Bash:

```sh
npm install
npm run dev
```

В PowerShell используй `npm.cmd` вместо `npm`, если политика Windows блокирует скрипты. Открой адрес, который напечатает Vite (обычно http://127.0.0.1:5173).

Для запуска двойным щелчком используй `start-qarhub.cmd`. Зависимости уже установлены на этом компьютере.

## Что работает

- Лента с поиском по тексту, машине и автору; фильтры по марке и теме, сортировка по новизне и популярности, решённые вопросы.
- Просмотр обсуждений, создание вопросов и записей бортжурнала, ответы, отметка решения автором вопроса.
- Лайки и избранное с возможностью отменить действие.
- Каталог сообществ и локальные подписки на марки.
- Гараж с маркой, моделью, годом, двигателем и переходом к обсуждениям марки.
- Локальный профиль с именем, адаптивный интерфейс, клавиатурная навигация и закрытие диалогов через Escape.

## Границы первой версии

Это **локальный прототип**, а не запущенный многопользовательский форум. Данные хранятся в localStorage браузера под ключом `qarhub:v1`. Они сохраняются при перезагрузке, но не переносятся на другие устройства и исчезнут при очистке данных сайта. Прототип не предназначен для хранения персональных или секретных данных.

Начальные авторы, публикации, ответы и реакции вымышлены. Фотографии иллюстративные. Новые записи пока текстовые: загрузка собственных фотографий, регистрация, серверная база, уведомления и модерация ещё не реализованы. Фильтрация по модели сейчас доступна через текстовый поиск; отдельный каталог поколений и двигателей — следующий этап. Подписки пока сохраняют членство и не отправляют уведомления. Адрес обсуждения с `?post=` работает только при наличии этой записи в текущем браузере.

## Проверки

```sh
npm run build
npm test
```

Браузерные тесты используют установленный Microsoft Edge и сами запускают сервер на порту 5173. Проверяют поиск, публикацию, ответы и решение, избранное, гараж, подписки, бортжурналы, мобильную навигацию и восстановление после повреждённого хранилища. Скриншоты сохраняются в `.artifacts/`.

## Структура

- `src/App.tsx` — экраны и взаимодействия.
- `src/Modal.tsx` — доступные диалоги с фокусом и Escape.
- `src/data.ts` — типы, марки и демонстрационные публикации.
- `src/storage.ts` — чтение, проверка и сохранение локальных данных.
- `src/styles.css` — оформление и адаптивность.
- `public/images/` — локальные фотографии.
- `tests/` — проверки пользовательских сценариев.

## Дальнейшая разработка

1. Серверная база: пользователи, автомобили, темы, ответы, избранное, жалобы.
2. Регистрация и сессии; проверка прав автора на сервере.
3. Загрузка фотографий с ограничениями типа и размера.
4. Каталог марок → моделей → поколений → двигателей.
5. Модерация, защита от спама, ограничения частоты запросов.
6. Развёртывание, резервные копии и подключение домена qarhub.kz после его регистрации.
